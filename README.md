# Vesc-dash

Neon-styled VESC dashboard mockup built with React, TypeScript, and Vite.

## Available screens

- Main dashboard with a large speed gauge, gear controls, and live telemetry cards
- Gear statistics view with a per-gear limits table and bottom navigation

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
